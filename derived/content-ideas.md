# Content ideas

A running list of things to write about in future. This is a *generative* artifact for the
QUERY / social phase — not a wiki page. Ideas live here, not in `/wiki/` (wiki pages must
trace back to the book via `appears_in`; ideas have no chapter yet).

Keep each idea grounded where possible: note the chapter or `[[wiki page]]` it grows out of,
so the backlog compounds with the audit rather than floating free.

## How to add an idea

Each entry should capture, at minimum:

- **Idea** — the working title or one-line description.
- **Format** — post, video, thread, app explainer, newsletter, etc.
- **Angle / hook** — what makes it worth reading; the take.
- **Grounded in** — chapter(s) and/or `[[wiki pages]]` it draws on (or "ungrounded" if new).
- **Audience** — who it's for.
- **Status** — idea | drafting | filed | dropped.
- **Notes** — anything else (open questions, dependencies, claims that need support).

When asked to add an idea, prompt me for any of these fields I have not provided before writing it in.
