## What was decided — full summary

### Activating/Calming (carried from previous session, now fully actionable)

Elevated to Tier 1 through-line. Introduced across the book in sequence:

- **Ch4 end:** concept established (unnamed) as natural completion of CEO metaphor
- **Ch5:** first formal use of terms, attached to caffeine behaviour (not adenosine)
- **Ch6, Ch7, Ch8:** appends at key moments; Ch7 (cortisol) is the strongest fit

### Concepts folded into Activating/Calming

- **Activating System / Calming System (Ch18):** currently introduced as new named terms
  for sympathetic/parasympathetic. Change: stop treating as a new introduction. Extend
  existing vocabulary instead — "here's the mechanism behind what you've been doing."
  The terms remain; the fresh introduction moment is removed.
- **Calm-good vs Hyped-good (Ch8, Ch15, Ch21):** dissolves into A/C vocabulary entirely.
- **Top-down / Bottom-up (Ch18):** dissolves into A/C vocabulary.

### Concepts removed entirely

- **3 Categories (body clock / nervous system / remove disrupters):** removed as a named
  concept. Currently appears in Ch9 and Ch25. Both chapters need updating.
- **Fitness Analogy:** demoted from Tier 1. Retained only as a rhetorical premise-setter
  in early chapters. Not carried forward as a named concept.

### Concepts retained unchanged

- **Sleep Window:** stays as named observable phenomenon.
- **Feedback Loop / 3-Layer Tracker:** stays unchanged.

### Program structure — headline number and framing

The headline changes from **16 habits** to **12 habits**.

The distinction between habits, tools, and setup was considered in depth:
- **Can't sleep routine** was initially classified as a tool, then reclassified as a habit.
  Rationale: insomniacs use it daily until recovery makes it unnecessary — it is a habit
  you build and then phase out, not a reactive technique.
- **Meditation nap (Ch19)** was the only chapter where "habit" is slightly misleading.
  Decision: call it a habit for headline purposes; let Ch19's prose carry the nuance
  (the chapter already says "naps are a tool, not a habit" — the reader gets the
  distinction in context without needing a structural label).
- **Phase 1 chapters (Ch10–12):** unlabelled setup. No habit numbers. The phase name
  "get set up" carries the meaning.

## Where to begin

Ch9 is the most significant change and the structural lynchpin — it currently names
phases, habits, and categories in the way we are removing. Rewriting Ch9 first means
every other change has a clear anchor to refer back to.

Alternatively, the A/C append sequence (Ch4–Ch8) can be drafted first, since those
changes are smaller and more contained. Starting there builds the vocabulary before
arriving at Ch9.

Suggested order: Ch4 append → Ch5 append → Ch6/7/8 appends → Ch9 rewrite → Ch18
fold-in → Ch25 update → chapter title/ToC changes last.
