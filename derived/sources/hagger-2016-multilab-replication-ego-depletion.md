## Findings (close summary, not copied text)

- 30 labs approved, 24 collected data, 23 analysed; total N = 2,141.
- Depletion: a modified letter-'e' crossing task requiring people to hold back a learned response; control: simple version.
- Outcome: multi-source interference task (response inhibition), reaction time variability and mean reaction time.
- Effect d = 0.04 (95% CI −0.07 to 0.15) for both measures: consistent with no effect; 'if any, close to zero'.
- Moderate differences between labs; authors call for replications using other tasks.

### Willpower 'Running Out' Effect Vanishes in Big Replication

In a 2016 project, 23 laboratories around the world repeated a classic willpower experiment with more than 2,100 adults, all following the same plan registered in advance.

Half the participants did a fiddly task that meant holding back a habit they had just learned; the other half did an easy version. Then everyone did a second task needing self-control.

Those who had done the tiring task did no worse on the second one. The effect, if any, was close to zero.

**The main takeaway:** Using self-control on one task does not reliably leave less for the next, which undermines the idea of willpower as a fuel tank.
